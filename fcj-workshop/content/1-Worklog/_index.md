Typically, and as a standard, a worklog is carried out over about 3 months (throughout the internship period) with weekly contents as follows:

**Week 1:** [Getting familiar with AWS and basic AWS services](1.1-week1/)

**Week 2:** [Deploying a web server on EC2 with Nginx and using S3 for static resources](1.2-week2/)

**Week 3:** [Detailed configuration of EC2 t3.micro instance as the main application platform](1.3-week3/)

**Week 4:** [Cloud storage management with Amazon S3 and security setup using IAM Roles](1.4-week4/)

**Week 5:** [Setting up containerization environment on EC2 with Docker and Docker Compose](1.5-week5/)

**Week 6:** [Deploying application components into Docker containers and setting up Internal API](1.6-week6/)

**Week 7:** [Installing Nginx as a Reverse Proxy, configuring DNS with Route 53 and setting up HTTPS](1.7-week7/)

**Week 8:** [Setting up monitoring systems for EC2 logs and resources with alerting mechanisms](1.8-week8/)
